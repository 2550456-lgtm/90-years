# 星火长征 · 纪念中国工农红军长征胜利九十周年

一个用于纪念**长征胜利九十周年（1936—2026）**的网页作品。
全部为纯前端实现，无框架、无依赖、无构建。

## 结构

```
index.html          单页，六幕图、样式、脚本全部内联
assets/
  snow.mp4          第四章 翻越夹金山 开头视频（H.264）
  ending.mp4        终章 海报入场动画（HEVC，部分浏览器不支持，会自动降级为海报入场动画）
  music.mp3         背景音乐
```

> `index.html` 内的图片以 base64 内嵌，因此只要与 `assets/` 同目录，双击即可离线打开。
